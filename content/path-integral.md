The **path integral** framework for quantum physics builds on earlier foundations, as proposed by [[@^Feynman48]]. This formulation provides the foundation for the [[Standard Model]], by providing a recipe for integrating many different contributing pathways into an overall probabilistic calculation. In the Standard Model, [[Feynman diagram]]s provide the template for the terms to add to the path integral [[Lagrangian]], to account for all the different ways in which a set of particles might interact.

The path integral framework results in the Born rule for computing the probabilities of different outcomes, and it therefore is consistent with the [[Copenhagen]] interpretation of quantum mechanics, where the resulting normalized integral represents purely epistemic uncertainty about which specific path might have been taken on any given instance. The logic is that, somehow, all possible paths are explored in parallel, but, upon measurement, only one specific path is actually revealed, according to the computed probabilities.

By contrast, in the [[pilot wave]] framework, the physically real [[quantum wave]] explores all of these possible paths in parallel, with the discrete [[particle]]'s trajectory being thereby influenced by the quantum waves. To account for the full relativistic transmutation properties of the Standard Model, where particles can decay and transform into other particles, such events also need to be stochastic in nature, with the probabilities corresponding to those computed by the path integral approach. Establishing a framework where such dynamics naturally occur is a primary challenge for the [[Spinfield Model]].
