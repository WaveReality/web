The Pauli matricies $\vec{\sigma}$ are used to define a set of orthogonal basis vectors for [[spin]]. They are the unique set of _Hermitian_ (symmetric in a [[complex number]] sense) matricies for rotations in a 2x2 space.

There are a set of three such 2x2 matricies, $(\sigma_x, \sigma_y, \sigma_z)$:

{id="eq_pauli" title="Pauli matricies"}
$$
\vec{\sigma} = \left( \begin{bmatrix} 0 & 1\\
1 & 0 \end{bmatrix}, \begin{bmatrix} 0 & -i \\
i & 0 \end{bmatrix},  \begin{bmatrix} 1 & 0 \\
0 & -1 \end{bmatrix} \right)
$$

In addition, the 2x2 identity matrix is often used too.

See the [[Dirac]] wave function for the application of these matricies to a spinning wave function.
